# Nova Travel — сайт туров по Дагестану

Одностраничный адаптивный сайт на Flask, HTML, CSS и чистом JavaScript. Каталог загружается через `GET /api/tours`, заявки отправляются на `POST /book` и сохраняются в `bookings.json`.

## 1. Что понадобится

- Python 3.10 или новее
- Visual Studio Code
- Терминал VS Code

## 2. Откройте проект

Распакуйте папку `nova_travel` в удобное место и откройте её в VS Code: **File → Open Folder**.

## 3. Создайте виртуальное окружение

Откройте терминал VS Code (**Terminal → New Terminal**) и выполните команды из корневой папки проекта.

**Windows (PowerShell):**
```powershell
py -m venv .venv
.venv\\Scripts\\Activate.ps1
```
Если PowerShell запрещает запуск скрипта активации, можно выполнить:
```powershell
.venv\\Scripts\\activate.bat
```
(в обычной командной строке cmd).

**macOS / Linux:**
```bash
python3 -m venv .venv
source .venv/bin/activate
```

После активации в начале строки терминала обычно отображается `(.venv)`.

## 4. Установите Flask

```bash
pip install -r requirements.txt
```

## 5. Запустите сайт

```bash
python app.py
```

Откройте в браузере: **http://127.0.0.1:5000**

Остановить сервер можно сочетанием `Ctrl + C` в терминале.

## 6. Как проверить работу

- Главная страница: `http://127.0.0.1:5000/`
- Каталог туров в JSON: `http://127.0.0.1:5000/api/tours`
- Отправка формы: `POST http://127.0.0.1:5000/book`

При успешной отправке новая заявка добавляется в `bookings.json` в корне проекта. Файл создаётся автоматически при первой заявке.

## Примечания

- Для разработки используется встроенный сервер Flask. Не используйте `debug=True` в публичном production-развёртывании.
- Карта и изображения в демоверсии — локальные визуальные заглушки, внешние сервисы не требуются.
- Заявки хранятся в JSON-файле без базы данных. Для реального многопользовательского запуска потребуется более надёжное хранилище и защита от параллельной записи.
